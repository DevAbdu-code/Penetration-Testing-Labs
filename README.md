## 📌 About This Repository

This repository contains my **CTF writeups** and **security tools** – practical work from penetration testing challenges, capture the flag competitions, and security research.

###  Purpose

-  **Document** CTF challenge solutions
-  **Analyze** vulnerabilities and exploitation techniques
-  **Develop** security tools for reconnaissance
-  **Create** a portfolio of security research
-  **Track** progression in offensive security
